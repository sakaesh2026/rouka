タップで見本

廊下で走ると、スマホが声で知らせます。歩けたら、はなまるでほめます。

はじめの5秒は、スマホを持たせる時間として鳴りません。止めるときは、子どもの画面の右下にある かぎのボタンを2秒おしつづけます。

とまるあるくはしる

ゆれが黒い線（判定ライン ）より右に続くと「走った」と判断します。線は指で動かせます。左ほど鳴りやすくなります。

きびしさ

きびしめにすると、少しの走りでも鳴ります。

はかって合わせる（おすすめ）

子どもが持つのと同じ場所（首かけポーチ・ポケットなど）にスマホを入れて、まず「歩いてはかる」、次に「走ってはかる」。判定ラインが自動で決まります。子どもに持たせてはかるのがいちばん正確ですが、先生が持ってはかっても使えます。

声を出したほめた

    使い方と注意

    はじめての準備
    1. このファイルを GitHub Pages などにのせ、https:// で始まるアドレスを、iPhoneは Safari、Androidは Chrome で開きます。
    2. マナーモード（消音）を切り、音量を大きくします。「注意をためす」で聞こえるか確かめます。
    3. 「歩いてはかる」「走ってはかる」で、判定ラインを合わせます。
    4. 「見守りをはじめる」をおして、子どもに持たせます。
    5. 止めるときや休むときは、右下の かぎのボタンを2秒おしつづけて、先生メニューを開きます。
    うまくいかないとき
    • 声が出ない：マナーモードと音量を確かめてください。iPhoneはページを読み込み直すと直ることがあります。
    • 走っても鳴らない：判定ラインを左へ動かすか「きびしめ」に。「声が出るまで」を短くします。
    • 歩いているだけで鳴る：判定ラインを右へ動かすか「ゆるめ」に。首かけで大きくゆれるときは、ポーチを体に近づけます。
    • センサーの値が届かない：https で開いているか確かめます。iPhoneで「許可しない」をおしたときは、Safariのタブを閉じて開き直し、もう一度ボタンをおします。
    • 画面が消えてしまう：iPhoneは 設定 → 画面表示と明るさ → 自動ロック → なし。Androidは画面消灯までの時間を長くします。
    子どもに持たせるときのコツ
    • iPhoneは「アクセスガイド」（設定 → アクセシビリティ → アクセスガイド）で、このページから出られないようにできます。オプションの「モーション」は、オンのままにしてください。
    • Androidは「アプリ固定（画面の固定）」が使えます（端末によって設定の場所がちがいます）。
    • iPhoneは「シェイクで取り消し」（設定 → アクセシビリティ → タッチ）をオフにすると、走ったときに「取り消す」の表示が出るのを防げます。
    • 持たせる場所は毎回同じにします。場所を変えたら、はかり直してください。
    • 声がおもしろくて、わざと走ったりスマホをゆらしたりする様子があるときは、チャイムを切る、ことばを短くする、ほめる声を中心にする、などを試してください。
    • 体育や休み時間は、先生メニューの「休む」で止められます。
    • 画面をつけたままにするので、電池を多く使います。充電してから使ってください。

    設定・記録・録音は、このスマホの中だけに保存されます。どこにも送信しません。
